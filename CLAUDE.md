# simpletrim_rs

Rust binary crate (edition 2024). Entry point: `src/main.rs`.

## Commands
- `cargo build` / `cargo test` / `cargo clippy` / `cargo fmt`

## Repo rules
- Every code change gets a `CHANGELOG.md` entry and a patch version bump in `Cargo.toml` (e.g. 0.0.1 → 0.0.2). New entries go at the top under `## [x.y.z] - YYYY-MM-DD`; version must match `Cargo.toml`.
- Minor and major versions change only when the user asks.
- Do not edit this file (`CLAUDE.md`) unless the user asks.
- Do not commit anything to git, this is done by humans.
- If you want to add dependencies, ask for confirmation by the user.
